# Progress — Mnémo (Ralph Loop)

## Codebase Patterns

> Conventions à suivre pour rester cohérent. À enrichir à chaque nouveau pattern.

- **Stack** : Next.js 15 App Router, React 19, TypeScript strict, Tailwind v3, Supabase (RLS), Vitest (unit), Playwright (e2e).
- **Langue** : UI + contenu en français (accents sur majuscules obligatoires) ; code/identifiants en anglais.
- **Moteur** : logique de reco en `lib/engine/` — fonctions **pures**, sans dépendance UI, testées unitairement. Portée depuis `design-reference/.../simulator-archi-base-memorielle-v2.html`. Fichiers : `types.ts` (unions littérales via `as const`), `modules.ts`, `presets.ts`, `preset.ts` (decidePreset), `layers.ts` (buildLayers), `cost.ts`, `scores.ts` (8 dim avec clé `key`), `diagnostics.ts` (compliance/risks/kmChecks), `recommend.ts` (orchestrateur + bonus modules), `index.ts` (barrel). Point d'entrée : `recommend(profile): Recommendation`.
- **Design** : tokens de `design-reference/mn_mo_brand_identity/DESIGN.md`, portés dans `tailwind.config.ts`. Polices Space Grotesk (titres, `font-display`), Inter (corps, `font-sans`), JetBrains Mono (données/chiffres/clés/chemins, `font-mono`). Cartes `rounded-card` (14px), champs `rounded-input` (10px), boutons `rounded-full`. Élévation `shadow-elevation`. FontSize sémantiques : `text-display-lg`, `text-headline-lg/md`, `text-body-lg/md/sm`, `text-code-md`, `text-label-caps`.
- **Primitives UI** : `components/ui/{Button,Card,Chip,Input,StatusDot}.tsx` + helper `lib/utils/cn.ts` (clsx+tailwind-merge). Type `Confidence` (high/medium/low → 🟢🟡🟠) dans StatusDot. Composants = props typées étendant les attributs HTML, pas de `any`, return type `ReactElement`.
- **Tests** : Vitest + jsdom + @testing-library/react + jest-dom. `test/setup.ts` importe `@testing-library/jest-dom/vitest`. `@vitejs/plugin-react@^4` (épinglé : v6 exige vite 8, incompatible vitest 2/vite 5).
- **Sécurité** : zéro secret hardcodé (env/coffre) ; RLS sur toutes les tables Supabase ; pas de `any` TS sans commentaire justificatif.
- **Sources** : tout chiffre de coût affiché lie sa source (URL + date) + pastille de confiance 🟢🟡🟠 + disclaimer « une IA peut se tromper ».
- **Price feed (F4, `lib/pricing/`)** : logique pure (`extract`/`feed.buildObservation`) séparée des effets (`firecrawl` = `fetch` injectable, jamais throw → repli ; `cache` = TtlCache, `now` injectable). Secrets (`FIRECRAWL_API_KEY`) lus uniquement côté serveur (`app/api/pricing`), jamais exposés au client. Détection de variation par empreinte d'un snapshot daté (`baseline.ts`) **généré par le code** (`scripts/capture-baseline.mts`, jamais à la main). Pages usage-based (0 figure) → confiance medium + note manuelle, pas d'invention.
- **Provisioning** : l'agent (Lot 2) ne crée jamais de compte ni ne saisit de carte — l'utilisateur crée le compte, l'agent optimise après (OAuth/MCP).
- **Intégration sizing → recommend (S-018)** : `recommend(profile, prices = NEUTRAL_MEDIA_PRICES)` — **prix injectés**, moteur **pur** (zéro import `lib/pricing`). `applyMultimodalSizing` (`cost.ts`) injecte les coûts **dans** les couches : C6 = pool GPU (UNE fois) + usage API ; C5 = stockage ; C4 = forfait embeddings (jamais le GPU → anti double-comptage). `computeSetupCost` (backlog `MediaNeed.backlog`, tarif `api.ingest`). `Recommendation` étendu (`sizing`/`setupCost`/`costSources`/`verdict`) — consommateurs lisent seulement (typecheck 0 sans modif). UI = défaut neutre tant que `ResultsView` n'injecte pas `getMediaPricesEur()` (câblage = S-022). Invariant `totalCost = baseCost + moduleCost` **préservé** (sizing neutre si pas de `mediaNeeds`). `buildEnsemble(profile, prices?)` threade les prix.
- **Pricing médias (`lib/pricing/media-seed.ts` + `media-feed.ts`, S-017)** : seed sourcé (DÉFCON 1) en **devises natives** (`MultimodalPriceEntry.currency` ; Scaleway € / OpenAI·Google·Runway $) — **jamais de € figé** ; conversion en € = **étage FX dédié** (`normalizeMediaPricesToEur`) au runtime, taux **live Frankfurter (BCE), repli** sur taux BCE daté (`SEED_USD_TO_EUR`). `getMediaPrices()` = natif ; `getMediaPricesEur(rate)` = € pour le moteur. Audit trail complet : `docs/pricing/media-cost-sources.md` (figure + unité + URL + date + confiance par fournisseur). Conversions d'unité (car./image→min) bakées avec confiance `low` + note « estimation, à confirmer par devis ». Feed Firecrawl (`refreshMediaPriceFreshness`) = fraîcheur des pages seulement (ne réécrit pas un prix). **Sourcing = recherche web réelle (pages officielles), NON TROUVÉ assumé, jamais inventé.** **Revue Amine** : référent embeddings = **Qwen3-VL-Embedding** (open Apache 2.0, #1 MMEB-V2), self-hosté sur le GPU déjà compté → forfait C4 = **0 €** (anti double-comptage), pas Voyage. Pour les modèles « best-of » → **vérifier le classement (MMEB/MTEB) + licence**, ne pas figer un fournisseur de mémoire.
- **Catalogue de composants injecté (`lib/catalog/`, S-035, reco vivante spec n°3)** : les CHOIX techniques (jadis figés dans `layers.ts`) deviennent **données injectées**, comme les prix (S-018). `types.ts` (`Catalog`/`CatalogSlot`/`ComponentCandidate`/`Provenance` live·seed·flagged/`ComponentSovereignty`) ; `catalog-seed.ts` (`seedCatalog(preset, profile)` transpose `layers.ts` À L'IDENTIQUE — alternatives en **tableaux** (pas de split fragile) → round-trip exact ; source = calibration interne datée, confiance `medium`, **PAS** une source web) ; `reconcile.ts` (`reconcileCatalog(live, seed, profile)` pur, jumeau `pricing/reconcile` : live valide→`live`, sinon repli **seed** marqué `flagged`+`confidence low` ; profil `secret`/régulé dur ⇒ rejet `api-third-party`) ; `index.ts` barrel. `buildLayers(preset, profile, catalog = seedCatalog(...))` lit le catalogue (id/name/couleur/**coût** restent calculés — le catalogue ne porte PAS les coûts, DÉFCON 1) ; `recommend(profile, prices, catalog?)` + `buildEnsemble(profile, prices?, catalog?)` threadent (baseline ; variants sur seed car le spread coût/score est indépendant du catalogue). **Réutilise `Confidence` (StatusDot, `import type`) + `CostSource` (engine)**. Tests : caractérisation d'identité (choix/notes/alternatives/coûts exacts LIGHT/MEDIUM/HARD × mm × bitemp) + reconcile. La **veille live** (S-036) remplacera le seed par des candidats sourcés web.
- **Dimensionnement multimédia (`lib/engine/sizing.ts`, S-016)** : `costMultimodalSizing(profile, prices) → Sizing`, **pure**, prix INJECTÉS (`MultimodalPriceTable`, implémentée/sourcée en S-017). **GPU compté UNE SEULE FOIS** : charges `sovereign` (ingest+generate, toutes modalités) → charge cumulée → **un** palier `gpu` (jamais N pools) ; `api` ne consomme pas le GPU souverain (coût à l'usage porté par `WorkloadLine.monthlyCost`, **0** pour `sovereign`). Facteurs de modélisation (`TIER_QUANTITY`/`STORAGE_GB_PER_UNIT`/`GPU_LOAD_PER_UNIT`/seuils) = **hypothèses ±30 %** (comme `VOLUME_FACTOR`), **jamais des prix**. Besoin inactif (`ingest`+`generate` = `none`) filtré → sizing neutre. `GpuTier` validé à 4 paliers (ADR-010). Tests = **propriétés** (monotonie, anti-double-comptage, `api`≠`sovereign`, `generate`>`ingest`) plutôt que valeurs en dur.
